# Bass samples

`acoustic_bass/` (upright) and `electric_bass_finger/` hold one MP3 per MIDI note,
named by MIDI note number (33 = A1 to 57 = A3).

They come from the **Musyng Kite** soundfont as pre-rendered by
[gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts),
